# Contributing

Bug reports and pull requests are welcome.

- **Bug?** Use the bug-report form and paste the output of **Log → Run diagnostics → Copy**.
- **New scope that doesn't work?** Include the `HNDEC-xxxx` name, the seller listing, and the diagnostics.
- **Code:** keep `ne3web.py` dependency-free (standard library only) and the app free of trackers or network calls other than to the scope.
- Test desktop changes with `python3 src/earscope/ne3web.py -v`. Android changes can't be tested without a device, so say what you tried.

contribute it.
